# 📋 Liste des Composants Disponibles

## Composants UI (shadcn/ui)

Tous les composants suivants sont disponibles dans `components/ui/` :

- `accordion.tsx` - Accordéon pliable
- `alert.tsx` - Alertes
- `alert-dialog.tsx` - Dialogues d'alerte
- `avatar.tsx` - Avatars
- `badge.tsx` - Badges/étiquettes
- `button.tsx` - Boutons avec variantes
- `card.tsx` - Cartes
- `checkbox.tsx` - Cases à cocher
- `dialog.tsx` - Modales
- `dropdown-menu.tsx` - Menus déroulants
- `input.tsx` - Champs de saisie
- `label.tsx` - Labels
- `select.tsx` - Sélecteurs
- `separator.tsx` - Séparateurs
- `skeleton.tsx` - Placeholders de chargement
- `switch.tsx` - Interrupteurs
- `table.tsx` - Tableaux
- `tabs.tsx` - Onglets
- `textarea.tsx` - Zones de texte
- `toast.tsx` - Notifications toast
- `tooltip.tsx` - Infobulles

Composant de carte de casino avec :

- Providers de jeux
- Tooltips informatifs
- Animations au hover

Effet de particules dorées animées pour les éléments premium.

Éléments décoratifs en forme de diamants avec animation.

## Styles Utilitaires

### Classes CSS personnalisées
- `.glass-card` - Effet de verre avec backdrop-filter
- `.glass-card-overlay` - Variante pour overlays
- `.text-gradient` - Texte avec dégradé
- `.scrollbar-thin` - Scrollbar personnalisée fine

- `animate-jackpot-pulse` - Pulsation jackpot
- `animate-slot-spin` - Rotation de slot
- `animate-card-deal` - Distribution de cartes
- `animate-float-pulse` - Flottement avec pulsation
